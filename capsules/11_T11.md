# T11 - Evolution dans le metier du chercheur

## Intention

Montrer comment l'innovation transforme le metier de chercheur : casquettes multiples, conciliation, impact visible — sans opposer recherche et engagement.

## Ce que racontent les chercheurs (montage final)

Muriel : experience enrichissante ; « integrateur social » — rendre visible a quoi servait la recherche. Loic : comite scientifique + fonctions d'enseignant-chercheur ; impartialite. Jean-Jacques : conseil de surveillance. Questions du montage : ce que ca change dans le metier ; ce qu'il faut concilier.
